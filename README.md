# AI Mentor

Android application with History, Math, Programming and Science modules.

## Setup

1. Open this folder in Android Studio and configure the Android SDK.
2. Copy `gradle.properties.example` to `gradle.properties`.
3. Add your own Gemini API keys to the local `gradle.properties` file.
4. Sync Gradle and run the `app` module.

Local configuration, build outputs and signing keys are excluded from Git. Never commit real API keys. Use a server-side service for production credentials.
