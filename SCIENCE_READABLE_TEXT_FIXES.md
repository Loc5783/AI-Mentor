# Science readable-text fixes (V11)

This revision increases undersized text in the Science module while preserving the existing visual hierarchy and all functional fixes from V10.

## Main changes

- Increased hero descriptions from 13sp to 15sp.
- Increased menu-card descriptions from 12sp to 14sp.
- Increased list titles/subtitles from 14/12sp to 16/14sp.
- Increased small chat status, model status, safety notice, filters, dates and “View all” controls.
- Added explicit 13sp bottom-navigation label styles.
- Added explicit text sizes to Science buttons, radio options and chat actions.
- Increased several fixed card/list heights to prevent clipping after enlarging text.
- Increased periodic-table element number/name from 11sp to 12sp.
- Increased programmatically-created formula timestamps and quiz difficulty labels.

## Scope

Only Science typography and supporting layout heights were changed. API configuration, database logic, chat-history behavior and the other modules were not modified.
