# Grade 12 question-bank demo

This directory preserves the 1,800-question source bank and review history.
The deployed demo excludes AIM_PHY12_BANK01_Q149 and AIM_PHY12_BANK01_Q199.
Do not bulk-import all source CSV files without these exclusions.

The shared Supabase project hnxphwuaccztzanjcuca already contains 1,798 published
questions and 63 published demo quizzes (7 per subject). Cloning Git does not
recreate or migrate cloud data. Keep credentials in the existing ignored local
configuration; no credentials are included here.

The demo manifests under demo/ record cloud IDs and source mappings. They are
tracking artifacts, not scripts to run automatically on startup.

Independent read-only verification confirmed all 1,798 quiz snapshots match
source prompts, four options, answer keys, explanations and points. A completed
30-question Math session records 20 correct answers and 200 points.
Device UI and real network interruption checks remain unverified. Academic
correctness of every question has not been independently certified; this is demo
content. Historical agent reports must be read together with AUDIT-CODEX reports.

No application source changes were required for this data connection.
